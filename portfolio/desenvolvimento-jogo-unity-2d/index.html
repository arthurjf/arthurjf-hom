Sobre o Projeto

Visão Geral

Um jogo indie 2D criado em Unity que combina mecânicas de plataforma com puzzle-solving. O jogo utiliza geração procedural para criar níveis únicos a cada partida.

Recursos Principais

Geração Procedural

  • Algoritmo de geração de dungeons usando Perlin noise
  • Criação dinâmica de plataformas e inimigos
  • Garantia de solvabilidade de níveis

Sistema de Física

  • Motor de física customizado para otimização
  • Detecção de colisão pixel-perfect
  • Movimento suave com interpolação

Gameplay

  • Mecânica de salto duplo
  • Sistema de poderes coletáveis
  • Inimigos com IA comportamental
