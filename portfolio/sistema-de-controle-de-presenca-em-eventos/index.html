Sistema de Controle de Presença em Eventos

Aplicação web para check-in e check-out por código de barras e emissão de certificados para monitores de eventos.

Sobre o Projeto

Projeto acadêmico.

  • Aplicação web full stack em PHP e MySQL para check-in e check-out por código de barras, simplificando o cadastro e o acompanhamento de monitores.
  • Emissão de certificados digitais na participação dos monitores.
  • Projeto testado e utilizado em produção no evento Conhecendo o IFG 2023.
